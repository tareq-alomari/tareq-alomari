### 🧑‍💻 About Me

I am a **Software Engineer** specializing in backend architecture, system design, and building intelligent solutions. With a strong foundation in Computer Science, I focus on scalable N-tier architectures, RESTful APIs, and integrating AI models into real-world applications.

- 🔭 **Currently working on:** **Your Smart Shopping Agent** as a Backend Engineer with DemoSoft.  
- 🌱 **Deep diving into:** Microservices, Docker containerization, and advanced OCR/Computer Vision pipelines (PyTorch, YOLO).  
- ⚡ **Fun fact:** I designed and built an Arabic programming language compiler (**FahdLang**) from scratch.  
- 👨‍🏫 **Community:** Founder of the **"Fikr Barmji"** (فكر برمجي) developer community, dedicated to mentoring developers in algorithms and software engineering.  
- 💡 **Interests:** ERP Systems, E-commerce Platforms, and building CLI-based productivity tools.
